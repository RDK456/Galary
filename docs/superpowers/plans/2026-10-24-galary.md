# Galary Implementation Plan

**Goal:** OneUI-style glass media gallery + VLC player for Windows.
**Architecture:** WPF .NET 8 (`Galary/`). Scanner streams `MediaItem` batches to a virtualized grid. Thumbnails via Windows shell (`IShellItemImageFactory`, covers video/audio/pdf/office/images). Playback via LibVLCSharp.WPF in an in-app viewer overlay. Mica backdrop via DWM.
**Tech:** net8.0-windows, LibVLCSharp.WPF, VideoLAN.LibVLC.Windows, Microsoft.Web.WebView2 (pdf/text preview).

## Global Constraints
- Types: video, audio, image, doc. Skip `$Recycle.Bin`, `node_modules`, `.git`, `Windows`, `AppData`.
- Library groups by date; sorts by date/name/size/type/duration; sort persisted in `%LOCALAPPDATA%\Galary\settings.json`.
- Scan cache in `%LOCALAPPDATA%\Galary\cache.json` (deviation from design: JSON not SQLite; swap if >200k files).

## Review Focus
- Unreadable folder / access denied: scan continues.
- Zero-byte or corrupt media: tile shows type icon, no crash.
- File deleted after scan: viewer shows error, grid drops it on rescan.
- Huge folder (100k files): UI stays responsive (batched adds, virtualization).
- Unicode / long paths.

## Tasks
1. Scaffold csproj + App + Mica window. Verify: `dotnet build`.
2. `Models/MediaItem.cs`, `Services/Scanner.cs`, `Services/Library.cs` (cache, sort, group, dedupe). Verify: `--selftest` flag scans a temp dir and asserts.
3. `Services/Thumbs.cs` shell thumbnails, async cache.
4. Gallery UI: header, tab pills, grouped virtual grid, bottom nav, animations.
5. Viewer: LibVLC player + glass controls, image/pdf/text/office handling, network URL.
6. Build, run, screenshot, fix.
